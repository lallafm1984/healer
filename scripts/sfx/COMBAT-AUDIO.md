# 전투 효과음 제작

`combat.mjs`는 현재 전투음 91종의 소리 방향을 정의한다.
최초 작업은 기존 47종 교체와 23종 추가였으며, 2026-10-21 사제 작업에서
그중 3종을 다시 교체하고 전용 스킬·발동음 15종을 추가했다.
이후 사용자 요청으로 공통·사제 시전 시작음 2종을 제거했다.
사제 17종의 최신 제작·검수 기록은 [PRIEST-SKILL-AUDIO.md](PRIEST-SKILL-AUDIO.md)를 따른다.
근접·중장·활·마법 공격, 피격·막기·빗나감, 보호막, 파티원 능력,
보스 착탄과 모든 기믹 연출을 게임 이벤트에 연결한다.
지속 회복의 매 틱은 의도적으로 조용하게 유지한다.

2026-10-21 최신 길이 제한: 배경음을 제외한 전체 효과음 121개는 **최대 1.5초**다.
초과 파일 12개 중 천상의 찬가를 새로 만들고, 나머지 11개는 음정을 유지하여 1.45초로 줄였다.
`src/sfx/timing.ts`는 느린 재생에서도 마지막 40ms를 감쇠하고 1.5초에 종료한다.
생성 목록의 `keep`도 1.5초 이하로 제한한다. 전체 해시·길이 검수는 `priest-clear-review.json`에 기록했다.

main의 직업별 공격음 8종을 함께 유지한다. 사제 음원은 사용자 확정 상태이며
`priest-approved.json`과 `../../CLAUDE.md`의 지침을 따른다.

## 재생성

이미 설치된 Agent Audio의 Stable Audio 3 Medium 런타임을 사용한다.
많은 효과음을 만들 때 메모리를 줄이기 위해 텍스트 인코딩, 확산 생성,
오디오 디코딩을 별도 프로세스로 실행하고 각 단계의 모델을 재사용한다.
Agent Audio의 런타임 검사·고정 리비전 검사·생성 잠금을 그대로 사용한다.
유료 서비스 호출이나 자동 모델 다운로드는 없다.

PowerShell에서 저장소 루트를 기준으로 실행한다. 경로는 해당 PC의 설치 위치에 맞춘다.

```powershell
npm run sfx:combat -- `
  --agent-python E:/claude/agent-audio/.venv/Scripts/python.exe `
  --home E:/claude/.agent-audio `
  --review-python E:/claude/comfyui/.venv/Scripts/python.exe `
  --model E:/claude/healer/.sfx-raw/combat-20261020/models/models--laion--clap-htsat-unfused/snapshots/8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a `
  --work E:/claude/healer/.sfx-raw/combat-20261020 `
  --rounds 3
```

검수 환경에는 numpy, scipy, torch, transformers와 로컬 CLAP 체크포인트가 필요하다.
새 작업에는 새 `--work` 폴더를 사용한다. 같은 폴더에서는 완료한 후보와 중간 계산을 재사용한다.
3차까지 탈락한 항목의 방향을 수정했다면 `--start-round 4 --rounds 6`으로
같은 작업 폴더의 불합격 항목만 이어서 생성한다.

## 합격 기준과 한계

- 에너지가 가장 큰 본 효과음 구간을 정렬하고 자연스럽게 끝난 이벤트만 선택한다. 앞의 작은 클릭은 본 소리로 오인하지 않는다.
- 강한 잔향을 억지로 자르거나 페이드로 숨긴 후보는 불합격 처리한다.
- 무음·비정상 샘플·클리핑·휴대폰에서 약한 중역을 검사한다.
- 순간 클릭에 비해 소리 본체가 지나치게 약한 후보도 제외한다.
- 로컬 CLAP으로 의도한 재질·동작과의 유사도 및 말소리·노래·배경 소음 혼입 가능성을 평가한다.
- 불합격 항목은 프롬프트와 시드를 바꾸어 다시 생성한다.
- 선택된 전체 목록이 통과해야 OGG를 일괄 적용한다. 정해진 횟수 안에 통과하지 못하면 기존 파일을 보존한다.

이는 신호 분석과 모델 보조 판정이며 사람이 직접 들은 평가가 아니다.
음악적·미학적 적합성을 절대적으로 보장하지 않는다.
원본·후보별 판정은 `.sfx-raw`에, 적용 파일의 해시와 선정 근거는
`combat-review.json`에 저장한다.

## 2026-10-20 적용 결과

후보 155개를 검수해 82개를 불합격 처리하고 70종을 선정했다.
기존 47개 파일은 모두 다른 해시의 새 음원으로 교체했고, 누락된 23개를 추가했다.
마지막 결계사 지속 치유음은 15번째 후보에서 통과했다. 판정 문장과 합격 기준은
유지하면서 생성 지시와 원본 생성 길이(2초 → 3초)를 조정했다.

최종 검증: 단위 테스트 2,534개, 신호 처리 회귀 테스트 5개, 실제 브라우저 검사
29개(전투음 21개·배경음 8개) 통과. TypeScript 검사와 배포 빌드도 통과했다.
브라우저에서 실제 전투도 실행했다. 이 결과는 사람의 청음 평가를 포함하지 않는다.

## 게임 검증

`tests/combat-sound.test.ts`에서 이벤트 연결, 중복 억제, 완전 보호막 흡수를 검증한다.
`tests/e2e/combat-audio.mjs`는 실제 브라우저의 Web Audio 디코딩과 재생을 계측하여
70종 로딩, 7개 직업의 치유음, 동시 피격, 기믹, 음소거와 복귀를 확인한다.
오디오 API를 무음 모형으로 대체하지 않는다.

```powershell
npm run build
$env:E2E_ONLY = '전투 효과음'
npm run e2e
```
